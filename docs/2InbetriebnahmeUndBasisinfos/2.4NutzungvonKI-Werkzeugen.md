# 2.4 Nutzung von KI-Werkzeugen

Sie dürfen zum Lernen menschliche und künstliche Intelligenz verwenden. Was nicht allein von Ihnen stammt, müssen Sie jedoch stets kennzeichnen. Gerade KI kann das Lernen fördern oder behindern, je nachdem, wie Sie damit umgehen.

***Die Verwendung von KI-Werkzeugen ist in dieser Veranstaltung ausdrücklich erlaubt, sofern diese als Hilfsmittel angegeben wird.***

**Wann ist es nützlich?**

- Man findet einen Tippfehler einfach nicht.
- Man lässt sich eine Fehlermeldung oder eine Funktionsweise erklären.
- Man lässt ein selbst geschriebenes Script kommentieren (siehe unten).

**Wann ist es gefährlich?**

- Man lernt nicht, sondern lässt die KI die Aufgaben machen.
    - Die KI löst die Aufgaben zu kompliziert und nicht auf Anfängerniveau. Ohne KI lässt sich die Lösung dann kaum überarbeiten. Genau das ist im Praktikum aber notwendig.
    - Die KI hält sich nicht an die Konventionen dieses Scripts.
    - Am Ende des Semesters stehen die Prüfungen an, und die eigenen Kenntnisse fehlen.


***Lassen Sie sich immer nur schrittweise helfen und widerstehen Sie der Versuchung, ganze Aufgaben erledigen zu lassen.***

## Regeln für die Nutzung

Ich empfehle KI ausdrücklich als Lernhilfe. Sie ersetzt jedoch nicht das eigene Arbeiten.

Zunächst verweise ich auf die Regeln der Hochschule zur Nutzung von KI. Sie sind in einem [Positionspapier](https://www.hs-emden-leer.de/hochschule/organisation/einrichtungen/campusdidaktik/ki-in-der-hochschullehre) zusammengefasst.

Geben Sie keine personenbezogenen Daten und keine vertraulichen Unterlagen in externe KI-Dienste ein.

### Kennzeichnung im Kommentarheader

***Jedes Script, an dem eine KI beteiligt war, ist zwingend um einen Kommentarheader zu ergänzen.*** Das gilt für Chat-Anwendungen ebenso wie für KI-Assistenten, die in Editoren eingebaut sind. Ein Beispiel mit Platzhaltern in Zeile 2 und 3 sieht wie folgt aus.

```python linenums="1" hl_lines="1-3"
# Interne LED blinken lassen
# Script erstellt von <KI-Werkzeug und Modell>
# <Vorname Nachname>, <Datum>
from machine import Pin
from time import sleep

# Interne LED als Ausgang festlegen
led = Pin('LED', Pin.OUT)

# LED im Wechsel ein- und ausschalten
while True:
    led.toggle()
    sleep(0.5)
```

Die Angabe richtet sich nach dem Anteil der KI. Es gibt drei Varianten.

1. `Script erstellt von <KI-Werkzeug>`<br>
    Diese Angabe gilt, wenn die KI den Hauptteil erstellt hat und nur geringfügige Änderungen erfolgt sind.

2. `Script erstellt mit Hilfe von <KI-Werkzeug>`<br>
    Quellcode und Struktur müssen einen erheblichen Eigenanteil aufweisen. Andernfalls ist Variante 1 zu wählen.

3. `<Teil> erstellt mit Hilfe von <KI-Werkzeug>`<br>
    Stammt ein abgrenzbarer Teil von der KI, ist dieser Teil genau zu benennen, z. B. `Funktion blinken() erstellt mit Hilfe von <KI-Werkzeug>`.

Unabhängig von der Variante müssen Sie jede Zeile Ihres Scripts erklären können.

### KI kommentieren lassen

Gut geeignet ist KI als Kommentator für vorhandenen Code. Die folgende Anfrage lässt sich mit jedem KI-Werkzeug stellen.

**Anfrage**

```text
Hinweis: Ich studiere im 1. Semester und habe keine Ahnung von Programmierung.
Kommentiere mir das Script (MicroPython für Raspberry Pi Pico) so ausführlich, dass ich es gut verstehe.

from machine import Pin
from time import sleep
led = Pin('LED', Pin.OUT)
while True:
    led.toggle()
    sleep(2)
```

**Mögliche Antwort**
```python linenums="1"
# Importieren der notwendigen Module
from machine import Pin  # Das Modul 'machine' enthält Klassen zur Steuerung der Hardware des Raspberry Pi Pico. Hier wird speziell die Klasse 'Pin' importiert.

from time import sleep   # Das Modul 'time' enthält Funktionen zur Zeitsteuerung. Hier wird speziell die Funktion 'sleep' importiert.

# Initialisieren der LED
led = Pin('LED', Pin.OUT)  # Ein Pin-Objekt namens 'led' wird erstellt. Der Parameter 'LED' steht für den integrierten LED-Pin des Raspberry Pi Pico. 'Pin.OUT' bedeutet, dass dieser Pin als Ausgang konfiguriert wird.

# Endlosschleife
while True:  # Dies ist eine Endlosschleife, die ununterbrochen läuft.
    led.toggle()  # Die Methode 'toggle()' wechselt den Zustand der LED. Wenn sie an ist, wird sie ausgeschaltet und umgekehrt.
    sleep(2)      # Die Funktion 'sleep(2)' pausiert das Programm für 2 Sekunden, bevor die Schleife erneut durchlaufen wird.
```

- Sie haben die Erstinstallation vorgenommen und die interne LED anschalten können. Damit sind Sie einsatzbereit für die kommenden Aufgaben.
- Sie können Scripte in Thonny schreiben und abspeichern, sowohl auf einem lokalen Computer als auch auf dem Pi Pico Board.
- Sie wissen, dass jedes Script einen Kommentarheader benötigt.
- Sie wissen, wie Sie KI-Werkzeuge sinnvoll nutzen und dass jede Nutzung im Kommentarheader anzugeben ist.
